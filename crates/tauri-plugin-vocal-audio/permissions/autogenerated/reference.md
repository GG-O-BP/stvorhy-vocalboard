## Default Permission

Vocalboard 오디오 환경 플러그인 기본 권한

#### This default permission set includes the following:

- `allow-check-permissions`
- `allow-request-permissions`
- `allow-configure-session`
- `allow-release-session`
- `allow-set-keep-screen-on`
- `allow-current-route`
- `allow-start-foreground-service`
- `allow-stop-foreground-service`
- `allow-exclude-from-backup`
